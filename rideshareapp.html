Project

RideShareApp

A JavaFX ride-sharing app that models the core features of a transportation service: user login, profile management, ride requests, map visualization, and payment handling.

JavaJavaFXFXML MavenMVC

View source on GitHub

Features

  • Login system: basic username and password validation with a transition into the main dashboard
  • Modular UI navigation: profile, map, and ride request pages loaded dynamically with FXMLLoader
  • Profile management: update username, password, and contact info, and submit support tickets
  • Payment methods: add card information with CVV and expiration validation
  • Ride request: request a ride and calculate estimated cost and distance
  • Map display: placeholder view for integrating a mapping service
  • MVC structure: a clear separation between controllers, services, and views

How it's organized

The app follows an MVC structure. Controllers handle each screen (login, main dashboard, profile, ride request, map, and sign up), services handle the underlying logic (profile, payment, ride request, and map), and FXML files define the views. Screens are swapped in and out through FXMLLoader rather than opening new windows.

Future improvements

  • Database integration for the payment and profile services
  • A real map API, such as Google Maps
  • Saved ride history

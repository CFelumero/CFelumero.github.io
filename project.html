Project

A list of the computer science projects I've worked on so far, plus a description of my idea for the COMP335 final project.

Projects so far

Greenwall

A self-watering hydroponic wall built at the BSU Think Tank, for the campus makerspace. 24 plant cells across 4 sections, monitored by 4 Arduino Megas and controlled by a Raspberry Pi running a Flask backend. I did the software and electrical design.

RideShareApp

A JavaFX ride-sharing app built for a class assignment, with login, profile management, ride requests, map visualization, and payment handling, structured with MVC.

Frogger inspired game project

A road and river crossing arcade game built in Python with the Arcade library, for a class assignment. Later ported so the same unmodified Python code runs live in the browser through Pyodide.

Robot2023

Robot code for FIRST Robotics Team 5494's 2023 season, Charged Up, built on WPILib. I wrote this as a student on the team during senior year of high school, for fun and competition.

TRAIN

My senior capstone project: a robot that tracks and autonomously navigates toward objects using TensorFlow and a Raspberry Pi, researching how AI-driven robotics is changing the workforce.

COMP335 final group project idea

GitHub profile viewer

My idea for the final project is a GitHub profile viewer: you search a GitHub username, and the page shows that person's public profile information and list of repositories.

I picked this because it's simple to scope, doesn't need any account or API key to work, and there's no risk of it breaking during a demo.

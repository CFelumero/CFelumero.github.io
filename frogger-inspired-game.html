Frogger Inspired Game Project

A road and river crossing arcade game I built in Python for a class assignment, using the Arcade library for sprites, collision, and sound. The version below runs that exact, unmodified Python code in your browser through Pyodide (a build of the real Python interpreter compiled to WebAssembly), not a rewrite. The only new code is a small stand-in for the parts of the arcade library that need an actual desktop window, since a browser can't open one the way Python normally does.

How this actually runs

main.py, froggerFunctions.py, and froggerHelper.py here are byte-for-byte the same files from my GitHub repo. They get loaded into Pyodide's virtual file system and imported normally, exactly like running python main.py locally. The one piece that's new is arcade.py: a small shim that gives those files an arcade module to import, where things like Sprite.draw() or arcade.play_sound() forward to JavaScript canvas and audio calls instead of opening a native OpenGL window, since that's the one part of desktop Python a browser genuinely can't do. All of the actual game logic, movement, collision, spawning, and sprite flipping is running as originally written.
